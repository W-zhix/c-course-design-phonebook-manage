# 📞 C语言课程设计 —— 电话簿管理系统

## 📚 项目简介
基于C语言实现的电话簿管理系统，采用**单向链表**（头插法）存储联系人信息，支持数据的文件持久化保存。

## 🛠️ 功能列表
- ✅ 插入联系人（自动分配编号）
- ✅ 删除联系人（带二次确认）
- ✅ 按编号修改联系人信息
- ✅ 按姓名/手机号查询
- ✅ 展示全部联系人及统计信息（联系人总数、手机号总数）
- ✅ 文件保存与读取

## 💻 运行环境
- 开发工具：Visual Studio
- 语言标准：C99

## 🚀 快速开始
1. 使用VS打开 `phone.c` 并编译运行
2. 根据菜单提示输入数字进行操作
3. 数据自动保存在 `telephone.txt` 中

## 📝 备注
本程序为大一C语言课程设计实训作业，包含结构体、指针、链表、文件操作等核心知识点。
